# Encoding Commands

Encoding and decoding utilities for common data formats:

- **hex**: Encode/decode hexadecimal
- **base64**: Standard base64 encoding/decoding
- **html_entity**: Encode/decode HTML entities
- **punycode**: Encode/decode internationalized domain names
- **url_safe_base64**: URL-safe base64 variant
