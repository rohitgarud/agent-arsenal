# Common Commands

This group contains commonly used utility commands organized into categories:

- **datetime**: Time and date utilities (timestamp, convert, relative_time, epoch)
- **encoding**: Encoding/decoding utilities (base64, hex, url_safe_base64, punycode, html_entity)
- **text**: Text manipulation utilities (word_count, diff, sort_lines, template)
- **system**: System introspection (port_check, process_list, disk_usage)
- **network**: Network utilities (curl, dns_lookup, http_headers)
- **crypto**: Cryptographic utilities (password_gen, hash_verify)
- **code**: Code utilities (JSON formatting, URL encoding, JWT decoding)
- **identifiers**: UUID generation
